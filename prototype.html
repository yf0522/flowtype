05

一次听写的完整流程

1
按下热键全局监听捕获 fn / 快捷键，弹出浮窗
→
2
采集 + 识别AVCaptureSession 取音频 → SFSpeechRecognizer 本地流式转写
→
3
实时回显浮窗显示部分结果（已定稿/未定稿分段）
→
4
松开/再按停止识别，拿到最终文本，可选标点整理
→
5
插入光标智能粘贴 / 模拟键入到当前焦点输入框
推荐架构（原生 Swift，技术栈待你定）
┌─ 菜单栏 App (SwiftUI, LSUIElement) ────────────────────┐ │ │ │ HotkeyManager 录音浮窗 (Panel/NSWindow) │ │ 全局热键监听 实时波形 + 部分转写回显 │ │ (CGEventTap) ▲ │ │ │ │ 状态 │ │ ▼ │ │ │ VoiceRecorder ───────────┘ │ │ AVCaptureSession → SFSpeechRecognizer │ │ (requiresOnDeviceRecognition = true, zh-CN) │ │ │ 最终文本 │ │ ▼ │ │ TextInserter │ │ 智能粘贴 (NSPasteboard + ⌘V) / CGEvent 键入 / AX API │ └────────────────────────────────────────────────────────┘ 依赖系统授权：麦克风 · 语音识别 · 辅助功能 · 输入监控
  • VoiceRecorder 直接复用 Muxy 同款方案（已验证可行）：本地、免费、支持中文
  • TextInserter 默认「智能粘贴」：暂存剪贴板 → 写入文本 → 模拟 ⌘V → 恢复剪贴板（最通用可靠）
  • HotkeyManager 用 CGEventTap 才能监听 fn 键的按住/松开；普通快捷键也走它
  • 三个核心模块边界清晰、可独立测试，符合后续 TDD 推进
